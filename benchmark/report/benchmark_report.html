Fixed quantum protocol

  • Qamomile → CUDA-Q, target nvidia, GPU required.
  • Full HiGHS UC reference uses a 0.5% relative MIP-gap target and a 60-second time limit per dataset.
  • QAOA depth: 1; final shots: 256; optimizer fallback shots: 64.

  • Top-K is 10 in the fixed ten-generator benchmarks and increases as 10, 20, 30, 40, 50 in generator scaling.
  • Every unique quantum configuration is executed once as a discarded first run. The second and later runs are the only runs used in statistics.
  • The discarded run initializes CUDA, CUDA-Q/Qamomile and circuit-size-specific resources; all optimizer evaluations and candidate validation remain inside each measured runtime.
